# Campaign Manager - Frontend

A modern, responsive campaign management dashboard built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 📊 Dashboard with analytics and charts
- 📧 Campaign management with CRUD operations
- 🎯 Form validation with React Hook Form + Zod
- 📱 Fully responsive design
- 🎨 Modern UI with Tailwind CSS
- 🔒 TypeScript for type safety

## Tech Stack

- **Framework**: Next.js 12.3.4
- **Language**: TypeScript 4.8.4
- **Styling**: Tailwind CSS 3.2.4
- **Charts**: Recharts 2.5.0
- **Forms**: React Hook Form + Zod validation
- **Icons**: Emoji icons (no external dependency)

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```
